# TürKod Sitesi

[TürKod](https://github.com/YusufX-sys/turkod-ide) projesinin resmi dokümantasyon sitesi. Astro ve Starlight ile oluşturulmuştur.

🔗 Canlı site: https://yusufx-sys.github.io/turkod-site/

## TürKod Nedir?

TürKod, Türkçe komutlarla çalışan, yapay zeka destekli, açık kaynaklı bir kodlama ortamıdır (IDE). Programlamaya yeni başlayanlar için tasarlanmıştır.

## Bu Depo Ne İçeriyor?

Bu depo, TürKod'un dokümantasyon sitesini içerir: kurulum rehberi, canlı demo, dil öğrenme materyalleri ve sürüm notları.

## Geliştirme

\`\`\`
npm install
npm run dev
\`\`\`

Site `http://localhost:4321` adresinde açılır.

## Yapı

```
.
```
