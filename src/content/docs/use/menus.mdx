Menü çubuğunda sekiz menü vardır. Bu sayfada her birinin içindeki komutları sırayla bulabilirsin. Kısayolu olan komutların kısayolu menüde de Türkçe olarak yazar (ör. `Ctrl+Alt+Aşağı`). Kısayolları **Görünüm → Klavye Kısayolları…** ile değiştirebilirsin; değiştirdiğin kısayol menüde de görünür.

:::tip[Kısayolu hatırlamıyor musun?]
`Ctrl+Shift+P` ile ya da en üst satırdaki **Komut ara…** kutusuyla **Komut Paleti**'ni aç ve komutun adını yazmaya başla. Menülerdeki her komut burada kısayoluyla birlikte listelenir.
:::

## Dosya

<Ekran src={mDosya} alt="Dosya menüsü" />

| Komut | Kısayol | Ne yapar? |
|---|---|---|
| Yeni Sekme | `Ctrl+T` | Boş bir `Adsız-N.trpy` sekmesi açar |
| Dosya Aç | `Ctrl+O` | Bilgisayarından bir dosya seçip açar |
| Son Dosyalar | `Ctrl+Shift+O` | Yakın zamanda açtığın dosyaları listeler |
| Klasör Aç | — | Gezgin'de gösterilecek proje klasörünü seçer |
| Kaydet | `Ctrl+S` | Dosyayı kaydeder; adı yoksa ad sorar |
| Tümünü Kaydet | `Ctrl+Shift+S` | Değişen bütün sekmeleri birden kaydeder |
| Sekmeyi Kapat | `Ctrl+W` | Aktif sekmeyi kapatır |
| Farklı Kaydet | — | Dosyayı yeni bir adla/konuma kaydeder |

## Düzenle

<Ekran src={mDuzenle} alt="Düzenle menüsü: Geri Al, Yinele, Kes, Kopyala, Yapıştır, Tümünü Seç, Satıra Git, Bul, Bul / Değiştir, Yorum Aç/Kapat, Satırı Çoğalt, Satırı Yukarı/Aşağı Taşı" />

| Komut | Kısayol |
|---|---|
| Geri Al / Yinele | `Ctrl+Z` / `Ctrl+Y` |
| Kes / Kopyala / Yapıştır | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| Tümünü Seç | `Ctrl+A` |
| Satıra Git… | `Ctrl+G` |
| Bul | `Ctrl+F` |
| Bul / Değiştir | `Ctrl+H` |
| Dosyalarda Ara | `Ctrl+Shift+F` |
| Tanıma Git | `F12` |
| Alta / Üste İmleç Ekle | `Ctrl+Alt+↓` / `Ctrl+Alt+↑` |
| Sonraki Eşleşmeyi Seçime Ekle | `Ctrl+D` |
| Tüm Eşleşmeleri Seç | `Ctrl+Shift+L` |
| Adı Değiştir… | `F2` |
| Kodu Biçimlendir | `Shift+Alt+F` |
| Yorum Aç/Kapat | `Ctrl+/` |
| Satırı Çoğalt | `Ctrl+Shift+D` |
| Satırı Yukarı / Aşağı Taşı | `Alt+↑` / `Alt+↓` |
| AI Önerisi İste (hayalet kod) | `Ctrl+Shift+Boşluk` |

**Adı Değiştir** bir adı kodun her yerinde birden değiştirir; metinlerin ve yorumların içine dokunmaz. **Kodu Biçimlendir** Ayarlar'daki girinti genişliğine uyar.

## Araçlar

<Ekran src={mAraclar} alt="Araçlar menüsü: TürKod ⇄ Python Çevir, Düzelt, Kod İstatistikleri, TODO Listesi, Kod Arama Çevirici" />

- **TürKod ⇄ Python Çevir** — açık dosyayı öbür dile çevirip yeni sekmede açar.
- **Düzelt** — [Akıllı Düzeltme](/features/smart-fix/) motorunu çalıştırır.
- **Kod İstatistikleri**, **Yapılacaklar Listesi**, **Kod Arama Çevirici** — bkz. [Araçlar](/features/tools/).
- **TürKod Kabuğu (komut satırı)…** (`Ctrl+Shift+K`) — kabuğu programın içinde ya da ayrı pencerede açar; bkz. [Terminal](/features/terminal/#türkod-kabuğu-ve-türkod-terminali).
- **Yerel AI Modelleri…** — bilgisayarında çalışan ücretsiz yapay zekâ modellerini yönetir; bkz. [Yapay Zekâ Modelleri](/features/local-models/).
- **Kod Parçacıkları…** (`Ctrl+Shift+J`) — hazır kod kalıplarını ekler (Kod Parçacıkları eklentisi açıksa).

## Öğren

<Ekran src={mOgren} alt="Öğren menüsü: TürKod ile Kodlama Macerası (Kitap) ve Dokümantasyon Sitesi" />

- **TürKod ile Kodlama Macerası (Kitap)** — kurulumla gelen kitabı programın içinde, yeni bir PDF sekmesinde açar. Kitaba Başlat menüsündeki **TürKod** klasöründen de ulaşabilirsin.
- **Dokümantasyon Sitesi** — dokümantasyon sitesini tarayıcıda açar.

## Yardım

<Ekran src={mYardim} alt="Yardım menüsü: Arayüz Turu, GitHub Sayfası, Hata Bildir / Öneri Gönder, İletişim, Lisanslar, Hakkında / İmza" />

- **Arayüz Turu** — ekranı adım adım tanıtan turu başlatır ([Arayüz Turu](/use/tour/)).
- **Kodi ile Konuş** (`F1`) — yardımcı robot [Kodi](/features/kodi/)'yi çağırır ya da gönderir.
- **GitHub Sayfası** — projenin GitHub sayfasını açar.
- **Hata Bildir / Öneri Gönder** — GitHub Issues sayfasını açar. Bkz. [Katkıda Bulun](/contribute/).
- **İletişim** — geliştiriciye e-posta yazmak için e-posta programını açar.
- **Lisanslar** — TürKod'un MIT lisansını ve **Diğer açık kaynak lisansları**'nı gösterir.
- **Hakkında / İmza** — sürüm numarasını, bağlantıları ve [imza doğrulamasını](/features/security/) gösterir.
