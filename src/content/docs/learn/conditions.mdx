<p>Koşullar, kodun <strong>karar vermesini</strong> sağlar. Bu sayfada <strong>eğer / değilse_eğer / değilse</strong> yapısını, karşılaştırma işleçlerini ve mantıksal bağlaçları öğrenirsin. ## eğer / değilse

```
yas = 15
eğer yas >= 18:
    yazdır("Reşitsin")
değilse:
    yazdır("Reşit değilsin")
```

## değilse_eğer — birden çok koşul

```
not_ort = 76
eğer not_ort >= 85:
    yazdır("Pekiyi")
değilse_eğer not_ort >= 70:
    yazdır("İyi")
değilse:
    yazdır("Çalışmalısın")
```

:::tip[Şimdi dene]
`not_ort` değerini değiştir ve kodun hangi dala girdiğini izle.
:::

## Karşılaştırma ve Mantık

| TürKod | Python |
| ------ | ------ |
| `> < >= <= == !=` | aynı |
| `ve` | and |
| `veya` | or |
| `değil` | not |
| `içinde` | in |
| `aynı_mı` | is |

```
hava = "güneşli"
yağmur = Yanlış
eğer hava == "güneşli" ve değil yağmur:
    yazdır("Dışarı çık")
```

## Doğru / Yanlış / Hiçlik

```
aktif = Doğru
puan = Hiçlik
eğer aktif ve puan aynı_mı Hiçlik:
    yazdır("Çalışıyor")
```

## içinde ile üyelik kontrolü

```
meyveler = ["elma", "armut"]
eğer "elma" içinde meyveler:
    yazdır("Var")
```

:::caution[Dikkat]
`=` atama yapar, `==` karşılaştırır. Koşul içinde tek `=` yazmak en sık yapılan başlangıç hatasıdır.
:::
