## Ekrana Yazdırma ve Girdi

```
yazdır("Merhaba Dünya")
isim = girdi_al("Adın ne? ")
yazdır("Merhaba " + isim)
```

:::tip[Şimdi dene]
`yazdır` içindeki metni kendi adınla değiştir ve çalıştır.
:::

## Değişkenler ve Matematik

```
yas = 15
sonuc = (10 + 5) * 2
kalan = 7 % 3
us = 2 ** 5
```

| İşleç | Anlamı |
| ----- | ------ |
| `+ - * /` | dört işlem |
| `//` | tam sayılı bölme |
| `%` | kalan |
| `**` | üs |

:::caution[Dikkat]
`toplam` kelimesi listenin toplamını alan bir komuttur (sum). Bu yüzden değişken adı olarak `toplam` kullanma; `toplam_deger` gibi bir ad seç.
:::

## Tür Dönüşümleri ve Yardımcılar

```
tamsayı("42")
ondalıklı("3.14")
metin(100)
mantıksal(1)
uzunluk("TürKod")
aralık(5)
mutlak(-7)
yuvarla(3.7)
```

## Listeler

```
sayilar = [3, 1, 2]
sayilar.sona_ekle(4)
sayilar.sırala()
sayilar.tersine_çevir()
yazdır(sayilar)
```

## Döngüler

```
döngü i aralık(5):
    yazdır(i)

sayac = 0
döngü sayac < 3:
    yazdır(sayac)
    sayac = sayac + 1
```

- `kır` → döngüyü durdur (break)
- `devam_et` → o adımı atla (continue)
- `geç` → hiçbir şey yapma (pass)
