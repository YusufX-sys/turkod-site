## Ekrana Yazdırma ve Girdi

```
yazdır("Merhaba Dünya")
isim = girdi_al("Adın ne? ")
yazdır("Merhaba " + isim)
```

:::tip[Şimdi dene]
`yazdır` içindeki metni kendi adınla değiştir ve çalıştır.
:::

## Değişkenler ve Matematik

```
yas = 15
sonuc = (10 + 5) * 2
kalan = 7 % 3
us = 2 ** 5
```

| İşleç | Anlamı |
| ----- | ------ |
| `+ - * /` | dört işlem |
| `//` | tam sayılı bölme |
| `%` | kalan |
| `**` | üs |

:::caution[Dikkat]
`toplam` kelimesi listenin toplamını alan bir komuttur (sum). `toplam` adında bir değişken oluşturursan o dosyada `toplam(...)` komutu artık çalışmaz. Karışıklık olmasın diye `toplam_deger` gibi bir ad seç.
:::

## Sık kullanılan yerleşik fonksiyonlar

| TürKod | Python | Örnek |
| ------ | ------ | ----- |
| `en_büyük` / `en_küçük` | max / min | `en_büyük([3, 9, 4])` → 9 |
| `toplam` | sum | `toplam([1, 2, 3])` → 6 |
| `sırala_builtin` | sorted | sıralanmış yeni liste verir |
| `sıralı_numaralandır` | enumerate | sıra numarasıyla döngü |
| `harita` | map | her elemana işlem uygular |
| `süz` | filter | koşula uyanları seçer |
| `izdusum` | zip | iki listeyi eşleştirir |
| `hepsi` / `herhangi` | all / any | hepsi / en az biri doğru mu? |
| `üssü` | pow | `üssü(2, 10)` → 1024 |
| `tip` | type | değerin türünü verir |

```
meyveler = ["elma", "armut"]
için sira, meyve içinde sıralı_numaralandır(meyveler, 1):
    yazdır(sira, meyve)
yazdır("a", "b", ayırıcı="-")
yazdır("Yükleniyor", sonlandırıcı="...")
```

Çıktı:

```
1 elma
2 armut
a-b
Yükleniyor...
```

`ayırıcı=` değerlerin arasına, `sonlandırıcı=` satırın sonuna ne konacağını belirler.

## Listeler

```
sayilar = [3, 1, 2]
sayilar.sona_ekle(4)
sayilar.sırala()
sayilar.tersine_çevir()
yazdır(sayilar)
```

## Döngüler

```
döngü i aralık(5):
    yazdır(i)

sayac = 0
döngü sayac < 3:
    yazdır(sayac)
    sayac = sayac + 1
```

Bir listenin elemanlarını sırayla gezmek için `için ... içinde` kullanılır:

```
meyveler = ["elma", "armut"]
için meyve içinde meyveler:
    yazdır(meyve)
```

Daha fazlası için [Veri Yapıları](/learn/data-structures/) sayfasına bak.

- `kır` → döngüyü durdur (break)
- `devam_et` → o adımı atla (continue)
- `geç` → hiçbir şey yapma (pass)
