title: Varsayılan Kütüphaneler
description: Python standart kütüphanelerinin Türkçe karşılıkları.
---

Standart kütüphaneler Türkçe adla içe aktarılır: `içe_aktar matematik`.

## matematik

```
içe_aktar matematik
yazdır(matematik.karekök(16))
yazdır(matematik.pi_sayısı)
```

## rastgele

```
içe_aktar rastgele
yazdır(rastgele.rastgele_tamsayı(1, 10))
```

## tarih_saat

```
içe_aktar tarih_saat
yazdır(tarih_saat.şimdi())
```

## istatistik

```
içe_aktar istatistik
sayilar = [1, 2, 2, 3]
yazdır(istatistik.ortalama(sayilar))
```
