<div class="tk-learn-intro">
<p>TürKod, Python'un hazır kütüphanelerini <strong>Türkçe adlarla</strong> içe aktarır. Bu sayfada en çok kullanılanları öğrenirsin: matematik, rastgele, tarih, istatistik ve çizim.</p>
</div>

## matematik

```
içe_aktar matematik
yazdır(matematik.karekök(16))
yazdır(matematik.pi_sayısı)
```

## rastgele

```
içe_aktar rastgele
yazdır(rastgele.rastgele_tamsayı(1, 10))
```

:::tip[Şimdi dene]
Kodu birkaç kez çalıştır ve her seferinde sayının değiştiğini izle.
:::

## tarih_saat

```
içe_aktar tarih_saat
yazdır(tarih_saat.şimdi())
```

## istatistik

```
içe_aktar istatistik
sayilar = [1, 2, 2, 3]
yazdır(istatistik.ortalama(sayilar))
```

## kaplumbaga — çizerek öğren

```
içe_aktar kaplumbaga
kaplumbaga.ileri(100)
kaplumbaga.sola_dön(90)
kaplumbaga.ileri(100)
kaplumbaga.çember(50)
```

:::caution[Not]
Çizim örneği tam sürümde çalışır; Canlı Demo'da kütüphaneler yoktur.
:::
