## Geliştirme ortamı

<Steps>

1. Depoyu fork'la ve klonla.

2. Gereksinimler: Windows 10/11, Python 3.12, Flutter SDK (stable) ve Visual Studio 2022 "Desktop development with C++".

3. Python paketlerini kur:

   ```
   python -m pip install -r requirements.txt
   ```

4. Ayrıntılı derleme adımları depodaki `TurKod-v3.3.0/nasıl-build-edilir.txt` dosyasında.

</Steps>

## Testler

Göndermeden önce testleri çalıştır:

```
cd TurKod-v3.3.0
python -m unittest discover -s tests
python tools\tablo_tutarlilik.py
```

Yeni bir özellik ya da hata düzeltmesi için mümkünse test ekle. Sözlük (`turkod_ide/TurKod_Sozluk.txt`) ya da ilgili tablolar değiştiğinde `tools/tablo_tutarlilik.py` temiz geçmelidir.

## Değişiklik yaparken

- **Sözlük:** Karşılıklar çocukların anlayacağı, doğal Türkçe olmalı. Eski adları silme; geriye dönük uyumluluk için koru.
- **Satır sonları ve kodlama:** Dosyaların mevcut satır sonlarını (LF/CRLF) ve UTF-8 kodlamasını koru.
- **Kullanıcıya görünen metinler** Türkçe olmalı. Menü, kısayol ya da ayar değişirse kitap da güncellenmelidir.
- **İmzalı klasör:** `turkod_ide/` altındaki bir dosyayı değiştirmek imzayı geçersiz kılar; bu beklenen bir durumdur, imzayı yayın sırasında proje sahibi yeniler. Pull Request'inde manifest dosyalarına dokunma.

### Pull Request süreci

1. `main` dalından yeni bir dal aç (ör. `duzeltme/kaplumbaga-baslik`).
2. Küçük ve odaklı değişiklikler gönder; bir PR tek bir konuyu çözsün.
3. PR şablonundaki kontrol listesini doldur.
4. İnceleme sonrası istenen değişiklikleri aynı dala gönder.

Ayrıntılar: [CONTRIBUTING.md](https://github.com/YusufX-sys/turkod-ide/blob/main/CONTRIBUTING.md)

## İmzayı doğrulamak

TürKod; uygulama dosyalarını, kaynak kodu ve güncelleme bildirimlerini RSA-PSS (SHA-256) ile imzalar. Kaynak kodun imzasını **özel anahtar olmadan**, yalnızca ortak anahtarla doğrulayabilirsin:

```
cd TurKod-v3.3.0
python kaynak_imzala.py --dogrula
```

Kurulu programda doğrulama için bkz. [Güvenlik](/features/security/).
