Alttaki **TERMİNAL** paneli (`Ctrl+J`) iki işe yarar: çalışan programınla konuşmak ve komut çalıştırmak.

- Program çalışırken alttaki kutuda **Programa / kabuğa girdi…** yazar; yazdıkların programa gider (`girdi_al()` cevapları). `Ctrl+C` (seçim yokken) programı durdurur.
- Program çalışmıyorken kutuda **Komut…** yazar; yazdıkların Windows komutu olarak çalıştırılır (`dir`, `cd` gibi). `turkod ...` komutları da burada çalışır (aşağıya bak).
- `↑` / `↓` son 100 komutu geri getirir.
- Başlıktaki düğmeler: **TürKod Kabuğu** (program çalışmıyorken; kabuğu terminalin içinde açar), **ayrı pencerede aç**, **Hatayı AI ile açıkla** (program hatayla bitince), **Yazıyı Küçült**, **Yazıyı Büyüt** (ya da `Ctrl`+fare tekerleği), **Tüm çıktıyı kopyala**, **Temizle**, **Kapat**.

## Her sekmenin kendi terminali

Her sekmenin ayrı bir terminali vardır. Çıktı, `↑` ile geri getirdiğin komut geçmişi ve `cd` ile girdiğin klasör yalnızca o sekmeye aittir.

- Başka bir sekmeye geçince o sekmenin terminali daha önce açıldıysa o görünür; açılmadıysa terminal paneli kapanır. Geri döndüğünde eski terminal her şeyiyle yerinde bekler.
- `Ctrl+J` yalnızca açık sekmenin terminalini açıp kapatır.
- Ayarlar sekmesinin terminali yoktur.
- Aynı anda tek bir program çalışabilir. Program başka bir sekmede çalışıyorsa terminal başlığında hangi sekmede çalıştığı yazar; bu terminale yazdıkların o programa gitmez, komut olarak çalışır. Başka sekmede **Çalıştır**'a basarsan eski program durdurulur.

## Türkçe pip — kütüphane kurma

Kütüphaneleri Türkçe komutlarla kurabilirsin. Sadece `pip` yazarsan Türkçe yardım çıkar:

<Ekran src={pip} alt="Terminalde 'pip' yazınca çıkan Türkçe pip komutları yardımı" caption="Terminalde yalnızca pip yazınca" />

| Komut | Eş anlamlısı | Ne yapar? |
| ----- | ------------ | --------- |
| `pip yükle pandas` | `kur` | Kütüphaneyi kurar |
| `pip güncelle pandas` | `yükselt` | Kütüphaneyi günceller |
| `pip sil pandas` | `kaldır` | Kütüphaneyi kaldırır |
| `pip listele` | `liste` | Kurulu kütüphaneleri listeler |
| `pip eskiler` | `eskimiş` | Güncellemesi olanları gösterir |
| `pip bilgi pandas` | `göster` | Kütüphanenin ayrıntılarını gösterir |
| `pip ara pan` | `bul` | **Kurulu** kütüphaneler içinde arar |
| `pip dondur` | — | Kurulu paketleri `gereksinimler.txt` biçiminde listeler |
| `pip denetle` | `kontrol` | Bağımlılık uyumluluğunu denetler |
| `pip indir numpy` | — | Kurmadan indirir |
| `pip önbellek` | — | pip önbelleğini yönetir |
| `pip sürüm` | — | pip sürümünü gösterir |
| `pip yardım` | — | Türkçe yardımı gösterir |

**Türkçe bayraklar:** `--yükselt` (= `--upgrade`), `--evet` (= `--yes`), `--sessiz` (= `--quiet`), `--ayrıntılı` (= `--verbose`), `-g dosya.txt` (= `-r`, gereksinim dosyası).

- Türkçe karaktersiz yazım da olur: `pip yukle numpy`, `pip kaldir numpy`.
- Bir gereksinim dosyasındaki her şeyi kurmak için: `pip yükle -g gereksinimler.txt`
- Sürüm de belirtebilirsin: `pip yükle "pandas==2.2.0"`
- İngilizce komutlar (`pip install numpy`) da çalışmaya devam eder.

<Ekran src={pipBilgi} alt="Terminalde pip bilgi pygame komutunun çıktısı: Name pygame, Version 2.6.1" caption="pip bilgi pygame: kurulu sürüm ve kütüphanenin nerede durduğu" />

Kurduğun kütüphaneler kullanıcı klasöründe (`%LOCALAPPDATA%\TurKod\pip_packages`) saklanır, güncellemelerde korunur ve programlarında hemen kullanılabilir.

## turkod komutu (komut satırı)

Kurulumda **TürKod'u PATH'e ekle** seçeneğini işaretlediysen (ya da sonradan **Ayarlar → Sistem Entegrasyonu**'ndan açtıysan), herhangi bir komut isteminde TürKod programlarını doğrudan çalıştırabilirsin:

```
turkod oyun.trpy
```

IDE terminaline yazılan `turkod ...` komutları da IDE'nin içinde çalışır; bunun için PATH ayarı gerekmez. `turkod --yardim` bütün komutları listeler. En kullanışlıları:

| Komut | Ne yapar? |
| ----- | --------- |
| `turkod dosya.trpy` | Dosyayı çalıştırır |
| `turkod --kontrol dosya.trpy` | Yazım hatası var mı diye bakar |
| `turkod --duzelt dosya.trpy` | Akıllı Düzelt uygular (`--yaz` eklersen dosyaya kaydeder) |
| `turkod --bicimlendir dosya.trpy` | Kodu toparlar (`--yaz` ile kaydeder) |
| `turkod --python dosya.trpy` | Kodun Python hâlini gösterir |
| `turkod --turkod dosya.py` | Python dosyasını TürKod'a çevirir |
| `turkod --cevir "yazdır(1)"` | Tek bir satırı çevirir |
| `turkod --anlam yazdır` | Bir kelimenin çocuk dostu açıklamasını verir |
| `turkod --dersler` | Kabuktaki dersleri listeler |
| `turkod kabuk` | TürKod Kabuğu'nu açar |
| `turkod exe_yap dosya.trpy` | Programı EXE yapar; bkz. [EXE'ye Dönüştür](/features/exe/) |
| `turkod kaynak oyun.exe` | Bir TürKod EXE'sinin kodunu gösterir |
| `turkod logo` | TürKod logosunu harflerle bütün terminale çizer |
| `turkod --surum` | Sürümü gösterir |

`.trpy` dosya ilişkisi açıksa Dosya Gezgini'nde bir `.trpy` dosyasına **çift tıklamak** da onu küçük bir TürKod penceresinde çalıştırır. Düzenlemek için sağ tıkla → **Editör ile aç**.

## TürKod Kabuğu ve TürKod Terminali

**TürKod Kabuğu**, tek satırlık kodları hemen denediğin bir oyun alanıdır. Sol şeritteki kabuk düğmesi, `Ctrl+Shift+K` ya da terminal başlığındaki **TürKod Kabuğu** düğmesiyle açılır. Aynı kabuk, Başlat menüsünde ayrı bir program olarak da durur: **TürKod Terminali**.

- `TürKod>` yazısının yanına bir satır yaz, `Enter`'a bas; sonuç hemen gelir. Bloklar (`eğer`, `için` ...) boş bir satır gelene kadar devam eder.
- 10 ders içerir: `dersler` listeler, `ders 3` üçüncü dersi gösterir, `dene 3` örneğini çalıştırır.
- `anlam yazdır` bir kelimenin anlamını söyler; Python kelimesi yazarsan (`print`) TürKod karşılığını bulur.
- `yardım` bütün kabuk komutlarını listeler.
