---
title: Klavye Kısayolları
description: TürKod IDE'deki tüm klavye kısayolları.
---

Kısayolu hatırlamıyorsan `Ctrl+Shift+P` ile **Komut Paleti**'ni aç: her komut kısayoluyla birlikte listelenir.

## Dosya

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+T` | Yeni Sekme |
| `Ctrl+O` | Dosya Aç |
| `Ctrl+S` | Kaydet |

## Düzenleme

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+F` | Bul |
| `Ctrl+H` | Bul / Değiştir |
| `Ctrl+/` | Yorum Aç/Kapat |
| `Ctrl+Shift+D` | Satırı Çoğalt |
| `Alt+↑` / `Alt+↓` | Satırı Yukarı / Aşağı Taşı |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Alta / üste boş satır |
| `Ctrl+Shift+V` | Alt satıra yapıştır |
| `Tab` / `Shift+Tab` | Girinti artır / azalt |
| `Ctrl+=` / `Ctrl+-` | Yazıyı büyüt / küçült |

## Görünüm

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+J` | Terminal Aç/Kapat |
| `Ctrl+Shift+P` | Komut Paleti |
| `Ctrl+Shift+PageUp` / `PageDown` | Sekmeyi Sola / Sağa Taşı |

## Çalıştırma ve hata ayıklama

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+R` | Çalıştır |
| `F9` | Breakpoint Aç/Kapat |
| `F5` | Debug Başlat / Devam |
| `F10` | Adım At |
| `F11` | İçine Gir |
| `Shift+F11` | Dışına Çık |
| `F6` | Duraklat |
| `Shift+F5` | Debug Durdur |

## Otomatik tamamlama

| Kısayol | Ne yapar? |
| ------- | --------- |
| `↑` / `↓` | Öneriler arasında gezin |
| `Tab` / `Enter` | Öneriyi kabul et |
| `Esc` | Listeyi kapat |
