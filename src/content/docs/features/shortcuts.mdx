---
title: Klavye Kısayolları
description: TürKod IDE'deki tüm klavye kısayolları.
---

Kısayolu hatırlamıyorsan `Ctrl+Shift+P` ile **Komut Paleti**'ni aç: her komut kısayoluyla birlikte listelenir. Fareyi araç çubuğundaki bir düğmenin üzerinde beklettiğinde de kısayolu görünür. Menülerde kısayollar Türkçe yazılır (ör. `Ctrl+Alt+Aşağı`, `Ctrl+Shift+Boşluk`).

:::tip[Kısayolları değiştir]
**Görünüm → Klavye Kısayolları…** (ya da Ayarlar'daki düğme) bütün komutları kısayollarıyla listeler. Bir komutun yanındaki kaleme bas, istediğin tuş birleşimine bas ve **Ata** de. Tuş başka bir komutta kullanılıyorsa uyarı çıkar. **Varsayılana döndür** tek komutu, **Tümünü Sıfırla** hepsini eski hâline getirir. Yeni kısayol menülerde ve düğme ipuçlarında da görünür. Aşağıdaki tablolar varsayılan kısayolları gösterir.
:::

## Dosya

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+T` | Yeni Sekme |
| `Ctrl+O` | Dosya Aç |
| `Ctrl+Shift+O` | Son Dosyalar |
| `Ctrl+S` | Kaydet |
| `Ctrl+Shift+S` | Tümünü Kaydet |
| `Ctrl+W` | Sekmeyi Kapat |

## Düzenleme

| Kısayol | Komut |
| ------- | ----- |
| `Ctrl+Z` / `Ctrl+Y` | Geri Al / Yinele |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Kes / Kopyala / Yapıştır |
| `Ctrl+A` | Tümünü Seç |
| `Ctrl+G` | Satıra Git… |
| `Ctrl+F` | Bul |
| `Ctrl+H` | Bul / Değiştir |
| `Ctrl+Shift+F` | Dosyalarda Ara |
| `F12` | Tanıma Git |
| `F2` | Adı Değiştir… |
| `Shift+Alt+F` | Kodu Biçimlendir |
| `Ctrl+Alt+↓` / `Ctrl+Alt+↑` | Alta / Üste İmleç Ekle |
| `Ctrl+D` | Sonraki Eşleşmeyi Seçime Ekle |
| `Ctrl+Shift+L` | Tüm Eşleşmeleri Seç |
| `Esc` | Bul kutusunu ya da fazla imleçleri kapat |
| `Ctrl+/` | Yorum Aç/Kapat |
| `Ctrl+Shift+D` | Satırı Çoğalt |
| `Alt+↑` / `Alt+↓` | Satırı Yukarı / Aşağı Taşı |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Alta / üste boş satır |
| `Ctrl+Shift+V` | Alt satıra yapıştır |
| `Ctrl+"` | Seçimi tırnak içine al |
| `Tab` / `Shift+Tab` | Girinti artır / azalt |
| `Ctrl+=` / `Ctrl+-` | Yazıyı büyüt / küçült (`Ctrl`+fare tekerleği de olur) |
| `Ctrl+Shift+Boşluk` | AI Önerisi İste (hayalet kod) |

Yorum, satır çoğaltma, satır taşıma, çoklu imleç, `F2` ve `F12` gibi kısayollar yalnızca imleç editördeyken çalışır.

## Terminal

| Kısayol | Ne yapar? |
| ------- | --------- |
| `Enter` | Yazdığını programa gönderir ya da komutu çalıştırır |
| `↑` / `↓` | Önceki komutlar / girdiler |
| `Ctrl+C` (seçim yokken) | Çalışan programı durdurur |
| `Ctrl` + fare tekerleği | Terminal yazısını büyütür / küçültür |

## Otomatik tamamlama ve hayalet kod

| Kısayol | Ne yapar? |
| ------- | --------- |
| `↑` / `↓` | Öneriler arasında gezin |
| `Tab` / `Enter` | Öneriyi kabul et |
| `Esc` | Listeyi kapat |
| `Tab` | Hayalet kod önerisinin tamamını kabul et |
| `Ctrl+→` | Hayalet kod önerisinin bir kelimesini kabul et |
| `Esc` | Hayalet kod önerisini kapat |
| `Ctrl+Shift+Boşluk` | Beklemeden hayalet kod önerisi iste |

## PDF sekmesi

| Kısayol | Ne yapar? |
| ------- | --------- |
| `PageUp` / `PageDown` | Önceki / sonraki sayfa |
| `Home` / `End` | İlk / son sayfa |
| `Ctrl+=` / `Ctrl+-` | Yakınlaştır / uzaklaştır (`Ctrl`+fare tekerleği de olur) |
| `Ctrl+0` | Genişliğe sığdır |

## AI Asistan, Kodi ve arayüz turu

| Kısayol | Ne yapar? |
| ------- | --------- |
| `Enter` / `Shift+Enter` | AI'ya gönder / yeni satır |
| `Enter` | Kodi'ye gönder |
| `→` veya `Enter` / `←` / `Esc` | Turda ileri / geri / turu kapat |

:::tip[Türkçe Q klavye]
`AltGr` ile yazılan `| [ ] { } \` gibi karakterler kısayol sanılmaz; editörde normal yazılır. Türk klavyesinde `Ctrl+/` yerine `Ctrl+Shift+7` ya da sayı tuşlarındaki `/` da olur.
:::
