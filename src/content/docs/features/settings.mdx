Ayarlara sağ üstteki ⚙️ simgesinden ya da **Görünüm → Ayarlar**'dan ulaşırsın. Ayarlar bir sekme olarak açılır; değişiklikleri **Kaydet ve Uygula** ile kaydedersin.

## Temalar

Üç tema vardır: **Modern Koyu** (varsayılan), **Koyu** ve **Açık**. Tema, editördeki kod renklerini de değiştirir.

## Ayarlar

| Bölüm | Ayar | Varsayılan |
| ----- | ---- | ---------- |
| Genel | Tema | Modern Koyu |
| Genel | Yazı Boyutu (8–32) | 14 |
| Genel | Yazı Tipi (bilgisayarındaki fontlar) | Consolas |
| Genel | Otomatik Tamamlama | Açık |
| Genel | Otomatik Kaydetme | Kapalı |
| Editör Görünümü | Satır Numaraları | Açık |
| Editör Görünümü | Kelime Kaydırma | Kapalı |
| Editör Görünümü | Boşluk Göstergesi | Açık |
| Editör Görünümü | Sütun Çizgileri | Açık |
| Editör Görünümü | Minimap | Kapalı |
| Terminal | Terminal Yazı Boyutu | 13 |

**AI Asistan** ayarları için [AI Asistan](/turkod-site/features/ai/), **Düzeltme** ayarları için [Akıllı Düzeltme](/turkod-site/features/smart-fix/) sayfasına bak.

:::note[Satır numaraları]
Durma noktası (breakpoint) koymak ve kod katlamak için satır numaralarına tıklanır. **Satır Numaraları** kapalıyken bu iki özellik kullanılamaz.
:::
